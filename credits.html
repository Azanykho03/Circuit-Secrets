Circuit SecretsCOMPLAB 2

Course project: COMPLAB 2, Computer Engineering, Cebu Technological University – Danao Campus.

This student-built mystery game turns component recognition, circuit reasoning, and careful observation into an investigation. It is designed for Computer Engineering students and first-time players alike.

Project team: Student development team, CTU Danao. Individual contributor names were not supplied for this build.

Type

  • Oxanium — headings and display lockups. Google Fonts; SIL Open Font License 1.1.
  • Space Mono — short labels, measurements, and terminal data. Google Fonts; SIL Open Font License 1.1.
  • Barlow Semi Condensed — dialogue and longer reading. Google Fonts; SIL Open Font License 1.1.

Code and interface assets

  • Three.js — 3D rendering library, loaded from jsDelivr; MIT License. License text.
  • Lucide — interface icon path family in ui-icons.js; ISC License. See the included license.
  • assets/maps/campus-map.svg and the four assets/intro/*-cartoon.svg illustrations — original project artwork; no separate external license.
  • Home, gameplay, intro and component model geometry — created procedurally in this project’s JavaScript; no external model library or texture pack.
  • The archived PNG and illustrated PNG studies in assets/intro/ are not used by the current runtime. Their specific third-party provenance/license is not documented and should be confirmed before redistribution.

Sound

Music, interface cues, and room ambience are synthesized at runtime with the browser Web Audio API. The project does not ship external music or sound recordings.

Original project work

Story, interface code, procedural scenes, component models, and game-specific artwork are project-created. No separate source-code license was supplied with this build.
